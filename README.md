# TP_HW_2 Классы для управления рецептами и списками покупок
С помощью данной программы вы сможете создавать ингридиенты, добавлять их в рецепты, также есть очень удобная функция масштабирования, если нужно приготовить много порций, кроме того программа позволяет взаимодействовать с диетическими рецептами, назначать различные диеты
## Использование и установка
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/nikibobus/TP_HW_2
   cd TP_HW_2
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запуск
   Для запуска тестов нужно ввести в терминале:
   ```bash
   pytest
   ```
